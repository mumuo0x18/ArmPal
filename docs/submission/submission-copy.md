## 应用简介(≤2000 字)

** 臂伴 ArmPal 是一款面向居家上肢康复与老年防跌倒场景的 PICO 空间应用。**它不替代专业医疗建议,定位为"训练陪伴与动作引导"。**

**为什么做它**
术后上肢恢复期患者与 65+ 有跌倒风险的长者,去康复机构难、在家没人盯、动作对不对没人反馈,在外子女不放心。这不是把平板康复 App 搬进头显,而是只有空间计算才能成立的陪伴:真人比例示范、双手 26 关节实时纠正、固定位置的打卡习惯、多窗口的患者/家属双视角。

**核心体验**
1. **三窗协同**(Full Space 内三个 WindowContainer,多窗口为 Spatial 赛道基本要求):
   - 训练主窗:动作名/目标/进度/实时反馈,底部可切换 5 个坐姿动作(抬臂/前平举/左臂/颈部左右转/点头仰头);
   - 动作纠正侧窗:实时抬举角仪表 + 目标刻度 + 颜色反馈(达标绿/接近黄/不足红)+ 左右对称性;
   - 今日报告窗:本场结果、Room 持久化的周报(次数/活跃天数/连续打卡 streak)、动作质量分。
2. **手势实时纠正**:26 关节手部追踪 + 头显姿态推算肩位(可选 T-pose 校准),抬举角/对称性/DTW 轨迹质量分;反馈用"颜色 + 语音"双通道,适合长者。
3. **训练位锚点**(空间锚点 = 行为设计):首次"这里设为训练位",之后回到训练位自动识别、连续打卡;不在范围内提示"回到训练位或手动开始",全程降级不阻断。
4. **3D 示范者**:几何体人形与训练数据同源驱动(示范手臂角度 = 你的实时抬举角),后续可换 Tripo 生成的人形模型。
5. **家属卡片**:一键生成今日报告图(次数/最高抬举/连续天数 + 免责声明),系统分享面板直达微信。
6. **语音引导**:关键节点中文语音提示(完成/鼓励/纠正),可在报告窗一键开关。

**数据与合规**
- 手部追踪与训练数据全部**端侧处理、本地存储**(Room + DataStore),不上传云端;分享卡片需用户主动触发;
- 全流程文案避免"治疗/诊断/疗效",统一"训练陪伴/动作引导/活动度记录";
- 首次启动与报告页固定展示:"本产品不替代专业医疗建议,急性期或疼痛请遵医嘱"。

**工程与开源**
- PICO Spatial SDK 6.2.8(Kotlin + 声明式 SpatialUI);pico-cli 全流程构建;
- analysis 包(抬举角/状态机计数/DTW/校准估计)为**纯 Kotlin 无 SDK 依赖**,JUnit 单测覆盖,可直接复用;
- 动作模板 JSON 化(exercises.json),README 写清"如何新增一个动作模板",**开源可二次开发**(Apache-2.0);
- 30 分钟连续运行稳定性已验证(模拟器 soak:pid 存活、0 crash)。

**依赖与测试条件**
- PICO Space Pro / PICO Emulator(6.2 镜像);手部追踪与空间锚点仅在 Full Space 可用;
- 模拟器无真实手势时自动进入演示模式(明确标注,不冒充真实追踪),保证完整闭环可演示;
- 语音提示依赖设备 TTS 引擎,不可用时静默降级为文字+颜色反馈。

## 操作说明

1. 启动应用 → 阅读并确认「使用须知」;
2. 训练主窗顶部 chips 选择动作(默认坐姿抬臂);
3. 跟随提示抬臂:侧窗仪表达到绿色目标线并保持即计数一次;组间自动休息倒计时;
4. 全部组数完成后,报告窗生成今日结果;点「生成家属卡片」导出并分享;
5. (可选)点「这里设为训练位」创建空间锚点,下次到同一位置打卡;
6. (可选)报告窗可关闭语音提示。
